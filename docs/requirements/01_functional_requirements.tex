\subsection{1. Introduction}\label{introduction}

\subsubsection{1.1 Purpose}\label{purpose}

This document defines the complete set of functional requirements for
\textbf{ConceptCode v1.0}, an AI-powered adaptive learning platform
designed to assist NEET aspirants in structured, personalized
preparation. It serves as the foundational reference for system design,
development, testing, and evaluation.

\subsubsection{1.2 Scope}\label{scope}

ConceptCode v1.0 (MVP) will be a web-based platform accessible via
modern browsers. It will support authenticated student and administrator
users. The platform will integrate Google Gemini AI for intelligent
tutoring and Scikit-Learn-based machine learning for adaptive difficulty
and weak area detection.

\subsection{2. System Overview}\label{system-overview}

ConceptCode is structured around a core learning loop:

\begin{verbatim}
Student Registers → Attempts Practice/Tests → System Tracks Performance
       ↓                                                 ↓
AI Explains Doubts ← Weak Areas Identified ← ML Analyzes Data
       ↓
Student Improves → Dashboard Reflects Progress → Repeat
\end{verbatim}

The platform covers three NEET subjects: \textbf{Physics},
\textbf{Chemistry}, and \textbf{Biology (Botany + Zoology)}.
